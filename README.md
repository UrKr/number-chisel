# number-chisel

- `index.html`: the original Number Chisel puzzle. Select digits, apply a power or root, and splice the result back in.
- `chisel/index.html`: **Chisel**, a quick card game built on the same idea. Three gold target numbers sit above a row of digits. On your turn, tap a card (+1, −1, ×2, x² or Smash) and then a digit to change it. Make a target number appear to score. First to 5 points beats your 1–3 computer rivals. It's a single self-contained file, so open it in any browser.
