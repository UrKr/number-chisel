# number-chisel

- `index.html`: the original Number Chisel puzzle. Select digits, apply a power or root, and splice the result back in.
- `transmute/index.html`: **Transmute**, an alchemy card game built on the same idea. Three recipes (pairs of elements) sit above a shelf of elements. On your turn, tap a spell card (Heat, Cool, Mix, Double or Blow away) and then an element to change it. Get a recipe's two elements side by side to brew it and score. First to 5 brews beats your 1–3 computer rivals.
- `chisel/index.html`: **Chisel**, the earlier number version of the same game.

Each game is a single self-contained file, so open it in any browser.
