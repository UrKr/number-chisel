# number-chisel

- `index.html`: the original Number Chisel puzzle. Select digits, apply a power or root, and splice the result back in.
- `chisel/index.html`: **Chisel**, a card game built on the same idea. You play against 1–3 computer opponents. Strike runs of digits in a shared number with math tools, and carve out your secret target numbers. First to 12 points wins. It's a single self-contained file, so open it in any browser.
